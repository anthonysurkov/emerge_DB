Scope {
    This system will:
    (1) Hold all data and metadata affiliated with EMERGe;
    (2) Provide all tools necessary to add, remove, and otherwise
        manage EMERGe data, including a user interface;
    (2a) Provide processing tooling to incorporate EMERGe rawdata automatically;
    (2a) Provide logging capabilities to document all data processing;
    (3) Provide handles to requisition data for out-of-scope programs;
    (4) And orchestrate rawdata file management.

    This system will NOT:
    (1) Hold analysis nor modeling programs;
    (2) Generate visualizations nor conduct summary statistics;
    (3) Otherwise generate derivations of the data beyond a clean and orderly
        database.
}
